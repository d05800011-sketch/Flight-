# Табло вылета, прилёта и пролёта

Сайт с анимацией перелистывания символов. Три табло: **вылет**, **прилёт** и **пролёт** (борта в небе над аэропортом). Нажмите на любой рейс, чтобы открыть карточку с логотипом авиакомпании и подробностями.

## Структура

```
index.html                           сайт
data/flights.json                    вылеты и прилёты (обновляются автоматически)
scripts/update-flights.mjs           загрузка расписания из AirLabs
.github/workflows/update-flights.yml расписание запуска
```

## Запуск за 5 шагов

1. Создайте репозиторий на GitHub и загрузите в него все файлы с сохранением папок. Папка `.github` скрытая, при загрузке через браузер перетащите её вместе с содержимым.
2. Зарегистрируйтесь на [airlabs.co](https://airlabs.co) и скопируйте API-ключ из личного кабинета.
3. **Settings → Secrets and variables → Actions → New repository secret**: имя `AIRLABS_API_KEY`, значение ваш ключ.
4. **Settings → Pages → Deploy from a branch → main / root → Save**.
5. Вкладка **Actions → Update flights → Run workflow**. Через минуту в `data/flights.json` появятся реальные данные, а плашка на сайте сменится на «Реальные данные».

Пока ключа нет, табло вылета и прилёта работают на демо-данных.

## Откуда данные

| Табло | Источник | Ключ |
|---|---|---|
| Вылет, прилёт | AirLabs через GitHub Actions (`data/flights.json`) | нужен |
| Пролёт | [OpenSky Network](https://opensky-network.org), запрос прямо из браузера посетителя | не нужен |

**Пролёт.** Анонимный доступ OpenSky даёт 400 запросов в сутки на один IP, сайт обновляет данные не чаще раза в 45 секунд и только пока вкладка открыта. Если OpenSky недоступен или заблокирован браузером, табло показывает демо-борта, а в плашке внизу будет пометка. Покрытие ADS-B над Россией у OpenSky ограниченное, поэтому реальных бортов может быть мало.

## Карточка рейса

- Логотип подгружается с открытых CDN (`pics.avs.io`, затем `images.kiwi.com`). Если оба не ответили или логотипа нет, показывается цветной значок с кодом авиакомпании.
- Для вылета и прилёта: маршрут, время по расписанию и ожидаемое, задержка, выход или лента багажа, терминал, тип самолёта, время в пути. Поля, которых нет в данных, не показываются.
- Для пролёта: позывной, авиакомпания (по префиксу позывного), высота, скорость, курс, вертикальная скорость, расстояние до аэропорта, страна регистрации, ICAO24.

## Настройка

Необязательные переменные: **Settings → Secrets and variables → Actions → Variables**.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `AIRPORTS` | `SVO,LED,AER` | Аэропорты, которые обновляются. Доступны: SVO, DME, VKO, LED, KZN, AER, KGD, SVX |
| `BOARDS` | `dep,arr` | Что загружать: `dep` вылеты, `arr` прилёты |
| `MAX_PAGES` | `1` | Сколько страниц по 50 рейсов брать на аэропорт |

Аэропорты, которых нет в данных, на сайте показываются в демо-режиме.

## Лимиты AirLabs

Расход запросов в месяц: `аэропорты × табло × страницы × запусков`. При значениях по умолчанию и запуске раз в час это 3 × 2 × 1 × 720 = 4320 запросов. Сверьте с квотой вашего тарифа AirLabs в личном кабинете. Если она меньше, уберите аэропорты в `AIRPORTS`, оставьте одно табло в `BOARDS` или замените в `update-flights.yml` строку `cron` на более редкую (например, `'0 */3 * * *'` для запуска раз в 3 часа).

На бесплатном ключе AirLabs отдаёт до 50 рейсов за запрос и только на ближайшие часы вперёд, поэтому для крупных аэропортов ближайшие рейсы могут попасть не все. Если нужно полнее, увеличьте `MAX_PAGES`.

## Формат data/flights.json

```json
{
  "updated": "2026-11-06T10:15:00.000Z",
  "airports": {
    "SVO": [
      { "ts": 1793000000, "delay": 0, "flight": "SU 1234", "al": "SU", "dest": "СОЧИ", "iata": "AER",
        "gate": "B12", "term": "B", "ac": "A321", "dur": 150, "state": "scheduled" }
    ]
  },
  "arrivals": {
    "SVO": [ ]
  }
}
```

- `airports` вылеты, `arrivals` прилёты, ключ код аэропорта.
- `ts` время вылета или прилёта с учётом задержки (секунды Unix), `delay` задержка в минутах.
- `state`: `scheduled`, `departed` (только вылеты), `landed` (только прилёты) или `cancelled`. Статусы «Регистрация», «Посадка», «В пути» и другие сайт считает сам по времени.
- Для прилёта `gate` это лента выдачи багажа, `dest` это город вылета.
- Название города берётся из таблицы `CITY` в скрипте. Если кода нет в таблице, показывается город из ответа API или сам IATA-код. Добавьте нужные города в `CITY`.
